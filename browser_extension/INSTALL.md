# Install the Sipcount extension in Chrome (2 minutes)

You need the `browser_extension` folder on your computer.
- **Madhur:** it is already in OneDrive → `Madhur\AiMeetsSustaianability\browser_extension`.
- **Anyone else:** open https://github.com/mouliarya/sipcount → green **Code** button → **Download ZIP** → unzip it → you will find a `browser_extension` folder inside.

## Steps

1. Open Chrome and go to `chrome://extensions` (type it in the address bar).
2. Turn on **Developer mode** (switch, top right).
3. Click **Load unpacked** (button, top left).
4. Select the `browser_extension` folder (the folder itself, not a file inside it). Click **Select Folder**.
5. Sipcount appears in the list. Click the puzzle-piece icon next to the address bar and **pin** Sipcount so its icon stays visible.

## Try it

1. Open https://chatgpt.com, https://claude.ai or https://gemini.google.com and send any prompt.
2. A small blue number appears on the Sipcount icon — that is today's water in mL.
3. Click the icon for the details: last prompt, budget, 7-day chart, and the "a lighter model would have saved…" tip.

## Good to know

- The warning "can read and change your data on chatgpt.com, claude.ai, gemini.google.com" is expected. See `PRIVACY.md` — the extension has no way to send anything anywhere.
- "Developer mode" is needed only because the extension is not on the Chrome Web Store yet. Publishing there costs a one-time US$5 fee — a decision for later.
- When I ship an update, download the new folder and click the **↻ reload** icon on the Sipcount card in `chrome://extensions`.
- Works identically in Microsoft Edge: go to `edge://extensions` instead.
